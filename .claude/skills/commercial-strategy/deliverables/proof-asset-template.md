# Proof Asset Template — Creation and Validation

## Purpose

Proof assets are the currency of B2B credibility. This template covers creation, validation, and deployment of every type of proof. Proof must be specific, verifiable, and current.

### Type 2: Data Point / Statistic

```
DATA POINT: [HEADLINE STAT]

Claim: [Exact claim as it will appear in marketing — e.g., "Average Ghost Tax report identifies 47k EUR in hidden IT costs"]
Source: [Where does this number come from? Internal data / third-party report / industry benchmark]
Sample size: [N — how many data points support this claim?]
Date range: [When was this data collected?]
Methodology: [How was it calculated? Brief description.]
Confidence: [HIGH / MEDIUM / LOW]
Expiry: [When should this stat be refreshed?]
Usage: [Where is this stat currently used? Website, emails, LinkedIn, etc.]

Verification:
- [ ] Calculation independently verified
- [ ] Source is citable and current
- [ ] Stat is not cherry-picked (represents typical outcome, not best case)
- [ ] Would survive scrutiny from a skeptical CFO
```

```
- [ ] Company is recognizable to our target market

Strength: [1-5]

  4 = Named person, specific result, lesser-known company
  3 = Named person, general positive statement
  2 = Anonymous but specific
  1 = Anonymous and vague (don't use this)
```

## Proof Asset Lifecycle

### Creation
1. Identify proof need (what claim needs backing?)
2. Select appropriate proof type
3. Create draft using template above
4. Verify all facts and permissions
5. Rate strength (1-5)
6. Add to registry

### Deployment
- Match proof type to channel and funnel stage
- Awareness stage: Industry benchmarks, methodology proof
- Consideration stage: Sample deliverables, data points
- Decision stage: Case studies, testimonials, ROI data

### Maintenance
- Monthly: Check all ACTIVE assets for staleness
- Quarterly: Refresh data points and benchmarks
- On any customer milestone: Create new case study
- On any stat change: Update all instances across all channels

### Retirement
- Asset is >12 months old with no refresh available
- Underlying data has been contradicted
- Company/person in testimonial no longer relevant
- Better proof asset available for the same claim

## Pre-Revenue Proof Strategy (Ghost Tax Current Phase)

When you have zero customers, proof comes from:

1. **Methodology credibility**: Explain the 21-phase analysis pipeline. Depth impresses.
2. **Industry data**: Cite third-party research (Gartner, Flexera, FinOps Foundation) on the problem size.
3. **Sample output**: Show a redacted/synthetic report. Let them judge quality directly.
4. **Speed claim**: "48 hours" is verifiable on first purchase. Low-risk claim.
5. **Founder expertise**: Relevant background that explains why you can do this.
6. **Free scan**: The scan itself IS proof. It demonstrates capability before asking for money.

**What NOT to do pre-revenue**:
- Don't fabricate case studies
- Don't use "companies like yours" without named examples
- Don't cite projected ROI as if it were measured ROI
- Don't use stock testimonials or unnamed quotes
